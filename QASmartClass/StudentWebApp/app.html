Bài tập sẽ hiển thị khi GV giao

📂 Sẵn sàng · Có thể kéo thả file vào trang này để nộp
💡 Hướng dẫn
📥 NHẬN TÀI LIỆU:
• GV phát bài → tự động nhận file
• Tab "Tài liệu nhận" → Nhấn "Mở"
• File lưu tại thư mục Tài liệu
📤 NỘP BÀI:
Cách 1: "Nộp file" → Chọn file bài làm
Cách 2: "Viết bài" → Soạn trực tiếp
Cách 3: Kéo thả file vào trang này
📝 SOẠN TRỰC TIẾP:
• Tab "Soạn bài" → Viết nội dung
• Đặt tên file → Nhấn "Nộp bài viết"
• File .txt tự tạo và nộp cho GV
✅ File nộp sẽ tự động gửi tới GV. Kiểm tra trạng thái ở tab "Bài đã nộp".
