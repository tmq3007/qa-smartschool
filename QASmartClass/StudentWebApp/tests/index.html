🧪 QA SmartClass — E2E Test Runner

Automated Testing for Student Web App v2.0

🚀 Phương pháp 1: Tự động (Khuyến nghị)

Mở app.html với tham số ?e2e=1 để tự động tải E2E harness:

▶ Mở App + E2E Harness

Sau khi mở, nhấn F12 → Console → chạy:

E2E.runAll()

🔧 Phương pháp 2: Console Inject

Nếu app.html đã mở sẵn, dán đoạn sau vào DevTools Console (F12):

// Inject E2E Harness
const s = document.createElement('script');
s.src = '../tests/e2e-harness.js';
s.onload = () => console.log('✅ E2E Harness loaded! Run: E2E.runAll()');
document.head.appendChild(s);

Sau đó chạy: E2E.runAll()

📋 Phương pháp 3: Từng bước

1
Mở app.html trong browser
2
Nhấn F12 để mở DevTools Console
3
Chạy từng test riêng lẻ:
// Individual tests:
await E2E.testNavigation()   // T1: Navigation
await E2E.testDashboard()    // T2: Dashboard
await E2E.testQuizFlow()     // T3: Quiz
await E2E.testHandRaise()    // T4: Hand Raise
await E2E.testOverlays()     // T5: Overlays (10 types)
await E2E.testChat()         // T6: Chat
await E2E.testSubmit()       // T7: Submit
await E2E.testSurvey()       // T8: Survey
await E2E.testResults()      // T9: Results
await E2E.testSettings()     // T10: Settings
await E2E.testLesson()       // T11: Lesson
await E2E.testPersistence()  // T12: Persistence
await E2E.testUI()           // T13: UI
