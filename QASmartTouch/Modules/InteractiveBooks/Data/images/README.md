# Thư mục chứa ảnh bìa sách

Đặt các file ảnh bìa sách vào đây theo quy tắc:

**Quy tắc đặt tên:** `{seriesCode}-{subject}-{grade}-tap-{volume}.jpg`

**Ví dụ:**
- kntt-tieng-viet-4-tap-1.jpg
- kntt-tieng-viet-4-tap-2.jpg
- ctst-toan-4-tap-1.jpg
- cd-khoa-hoc-5-tap-1.jpg
- old-tieng-viet-3-tap-1.jpg

**Kích thước khuyến nghị:** 400x600 pixels (tỷ lệ 2:3)
